# jawny.github.io

The website for my iPhone apps, published with GitHub Pages at https://jawny.github.io/.

- `index.html`: the list of apps.
- `vaultio/`: Vaultio's home, support, privacy and terms pages. Their source is the `site/`
  folder of the Vaultio app repository; copy it here after changing it.

Static pages only: no scripts, cookies, analytics or third-party resources.
